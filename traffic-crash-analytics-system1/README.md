# Traffic Crash Analytics System

A data analytics and visualization project focused on traffic crash datasets using Python, Pandas, SQLite, and Jupyter Notebook.

This project explores real-world traffic accident data through data cleaning, aggregation, SQL analysis, and visualization pipelines.

---

# Features

- Data cleaning and preprocessing
- Multi-dataset aggregation
- SQLite database integration
- Exploratory data analysis (EDA)
- Statistical insights from crash records
- Data visualization with Python
- SQL-based analytical queries

---

# Tech Stack

- Python
- Pandas
- SQLite
- Matplotlib
- Jupyter Notebook
